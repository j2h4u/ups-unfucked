<objective>
Move category ① config/spec OUT of persisted model.json: stop persisting full_capacity_ah_ref (source
it from config at runtime via a BatteryModel.capacity_ah attribute) and stop persisting
physics.nominal_voltage / physics.nominal_power_watts (source them from constants.py). Split the mixed
physics blob so the learned keys (peukert_exponent, ir_compensation, rls_state) keep persisting
(HYG-01, HYG-02).

Purpose: these three values are never learned — full_capacity_ah_ref is already overwritten from
config.capacity_ah on every start (monitor.py:129), and nominal voltage/power are fixed hardware spec.
Persisting them makes model.json carry non-learned data and falsely implies the on-disk copy is
authoritative. After this plan, model.json holds no config/spec; the getters return the same values as
before, sourced live — AND the injected capacity_ah also drives the rated-capacity reported by
get_convergence_status (so health/MOTD reflect a non-default capacity_ah instead of the hardcoded 7.2).

Output: a NOMINAL_VOLTAGE constant, a capacity_ah-injected BatteryModel, rated_ah propagation through
get_convergence_status, a slimmed physics persistence path, and updated tests — all callers unaffected,
all computed values identical for the default config and correct for non-default capacity_ah.
</objective>
