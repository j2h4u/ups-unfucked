<objective>
Stop persisting category ② derived caches and recompute their values live each poll (HYG-03, HYG-04):
scheduled_test_timestamp / scheduled_test_reason / test_block_reason (scheduler output — health reads
live scheduler_manager.last_*), capacity_converged (derived from capacity_estimates CoV — health reads
live convergence_status.converged), and replacement_due (derived from soh_history regression — recompute
at read time). Then prove the strict loader still passes against a regenerated file and document the
one-time deploy strip (HYG-05).

Purpose: these five keys are recomputed outputs, never learned inputs and never decision gates. Health
already sources the first four live; only replacement_due was genuinely persisted-then-read, and its
single-poll regression is cheap to recompute. Removing them makes model.json hold only learned state
and removes the staleness/divergence risk of caching computed values on disk.

Output: a shrunk ModelState, a live compute_replacement_due(), scheduling/convergence writes removed,
consumers reading live values, dead tests removed and a replacement_due equivalence test added, and a
deploy note. Depends on Plan 01 (both edit model.py; sequential to avoid conflict).
</objective>
